# XTDS fork 模板格式

本 fork 只内置两个模板：

```text
templates/archive-warm/            默认暖白序章
templates/xtds-character-reveal/   可选第二幕空槽位
```

模板是**纯数据**。宿主读取 JSON 后通过 `__DSH_STARTUP_TEMPLATE__` /
`__DSH_STARTUP_TEMPLATE2__` 下发；运行时不会执行模板里的代码。

模板来源优先级：

```text
~/.dsh/startup-templates/<id>/template.json   用户覆盖（优先）
templates/<id>/template.json                  插件内置
```

配置里的 `template` 是第一幕，`act2` 是第二幕。默认：

```json
{
  "template": "archive-warm",
  "act2": ""
}
```

旧配置引用已删除模板时，会自动回退为 `archive-warm` 单幕，第二幕清空。

## 一、普通用户不需要手写 JSON

导入自定义形象走设置页按钮：

**设置 → 启动动画 → 第二幕 → 🖼️ 导入自定义形象**

宿主会：

1. 校验扩展名与图片魔数；
2. 接受 PNG / JPEG / WEBP / GIF，拒绝 SVG；
3. 限制单张不超过 20MB；
4. 复制到 `~/.dsh/startup-templates/xtds-character-reveal/`；
5. 生成一份用户模板并把 `act2` 设为 `xtds-character-reveal`。

「恢复内置占位」会删除这份用户覆盖并回到内置 `character-slot.svg`。

## 二、`archive-warm`（schemaVersion 1）

暖白序章是 steps 结构，默认五步：

```json
{
  "schemaVersion": 1,
  "id": "archive-warm",
  "name": "档案暖白",
  "author": "沈宏宏",
  "adaptedBy": "LeeRolling / XTDS",
  "homepage": "https://github.com/LeeRolling/dsh-boot-suite",
  "license": "MIT",
  "version": "1.1.2",
  "theme": {
    "accent": "#ff7500",
    "glitchA": "#ff3b30",
    "glitchB": "#2971b8"
  },
  "steps": [
    {
      "zh": "需要访问许可",
      "en": "ACCESS PERMISSION REQUIRED",
      "say": "Access permission required.",
      "audio": "line-1",
      "log": "等待用户授权…",
      "action": "grant",
      "btnZh": "授予访问权限",
      "btnEn": "GRANT ACCESS",
      "hold": 900,
      "progress": 0.34
    }
  ]
}
```

关键字段：

| 字段 | 说明 |
|---|---|
| `schemaVersion` | 1 = steps 结构 |
| `id` | 小写字母、数字、连字符；必须与目录名一致 |
| `author` | **原作者**，不能改成 XTDS |
| `adaptedBy` | 改版/维护者 |
| `homepage` | 上游来源或作者主页 |
| `license` | 模板自身许可；素材来源另写在 NOTICE/LICENCE |
| `steps[].zh/en` | 主字与副标题 |
| `steps[].action` | `grant` / `confirm` / `auto`；`confirm` 为旧模板兼容路径 |
| `steps[].card` | `true` = 显示暖白身份卡（名称 / 编号 / 权限等级） |
| `steps[].tvGlitch` | `true` = 卡片出现时闪一次轻量电视方格花屏 |
| `steps[].audio` | 音频槽位名；缺失时运行时回落 |
| `steps[].hold` | 该步最短停留毫秒；自动幕实际停留不会低于 1000ms（倍速播放也一样） |
| `steps[].holdExact` | `true` = 按 `hold` 精确停留，不等待语音时长 |
| `steps[].progress` | 进度显示 0–1 |

默认第二幕身份卡不再等待按键，配置如下：

```json
{
  "zh": "身份资料确认",
  "en": "IDENTITY VERIFICATION",
  "action": "auto",
  "card": true,
  "tvGlitch": true,
  "hold": 2000,
  "holdExact": true,
  "progress": 0.5
}
```

第 1 步仍由 `action: "grant"` 保留按钮 / Enter / 空格交互；提示文案不再显示。
按钮一出现就会接收点击；若在扫描线结束前点击，引擎会以扫描线 `animationend`
为基准，在其结束后 100ms 切到下一步，不再等待语音或额外淡出。

## 三、`xtds-character-reveal`（schemaVersion 2）

第二幕是时间轴图层结构，默认约 5.6 秒，分三段：

```text
扫描锁定 → 形象显影 → 收束退场
```

精简结构：

```json
{
  "schemaVersion": 2,
  "id": "xtds-character-reveal",
  "name": "自定义形象 · 闪烁揭示",
  "author": "XTDS",
  "license": "MIT",
  "version": "1.0.0",
  "duration": 5600,
  "segments": [
    { "name": "扫描锁定", "from": 0, "to": 1500 },
    { "name": "形象显影", "from": 1500, "to": 4300 },
    { "name": "收束退场", "from": 4300, "to": 5600 }
  ],
  "layers": [
    {
      "id": "character-slot",
      "type": "image",
      "pos": [640, 360],
      "size": [1280, 720],
      "src": "character-slot.svg",
      "fallbackSrc": "character-slot.svg",
      "keyframes": [
        { "t": 0, "opacity": 0, "scale": 1.04 },
        { "t": 930, "opacity": 1, "scale": 1.015 },
        { "t": 5000, "opacity": 0, "scale": 1.015 }
      ]
    }
  ],
  "effects": [
    { "type": "vignette", "opacity": 0.62 },
    { "type": "scanline", "opacity": 0.2 },
    { "type": "crt", "opacity": 0.24, "from": 0, "to": 3600 },
    { "type": "glitch", "opacity": 0.78, "speed": 1.35, "from": 520, "to": 1450 },
    { "type": "hud", "opacity": 0.42, "from": 0, "to": 3400 },
    { "type": "bloom", "opacity": 0.45, "speed": 0.85, "from": 1000, "to": 4300 }
  ]
}
```

### 坐标规范

- 画布逻辑尺寸是 **1280×720**。
- 所有图层的 `pos` 都写画布中心 `[640, 360]`。
- 位移写在关键帧的 `offsetX` / `offsetY`，不要用绝对坐标改 `pos`。
- `size` 表示图层显示尺寸，不是位置。

例如扫描线标题：

```json
{
  "id": "eyebrow",
  "type": "text",
  "text": "XTDS // REVEAL ENGINE",
  "pos": [640, 360],
  "align": "left",
  "keyframes": [
    {
      "t": 180,
      "opacity": 0,
      "offsetX": -586,
      "offsetY": -304
    }
  ]
}
```

### 图层与特效

支持的图层类型包括 `panel`、`image`、`video`、`text` 等。
`image` 图层必须有 `src`；建议同时提供 `fallbackSrc`。

特效类型：

```text
vignette / scanline / crt / glitch / hud / bloom
```

缺失图片时：

- 先尝试 `src`；
- 加载失败切到 `fallbackSrc`；
- 仍失败则跳过该图层；
- 动画继续播完并触发结束事件，不允许黑屏。

## 四、模板安全约束

1. 只能是 JSON 数据；禁止脚本、内联 JS、外链脚本和 `eval`。
2. `id` 必须匹配安全字符白名单，并与目录名一致。
3. 宿主校验 schema；字段不合法时拒绝该模板或回落默认。
4. 内置模板的素材只能来自本模板目录或明确允许的全局资源。
5. 用户导入图片只允许位图格式并校验魔数。
6. 不把第三方角色素材当 XTDS 原创；`author` / `adaptedBy` / `license` 必须如实。

## 五、模板商店与在线更新

本 fork 默认不连接模板商店，也不检查上游更新。

- 商店仅在显式设置 `DSH_STORE_URL` 时启用；
- 更新仅在显式设置 `XTDS_UPDATE_REPO` 时启用；
- 更新资产只接受 `xtds-start-dsh-win*.zip`；
- 未配置环境变量时相关功能应返回明确的未配置错误，而不是回退上游。

旧文档中的 GitHub 商店地址、鲸鱼娘默认第二幕和六幕默认序列已过时。
