DSH 暖白开机动画 · XTDS 定制版

我给 DeepSeek Harness 的启动动画做了一个定制版：默认只保留开屏前半段的暖白「技术档案」序列。

现在的默认流程是：
暖白档案底板 → 五步访问授权 → 验证通过 → 直接进入聊天。

不再自动进入后半段“黑暗中闪烁出角色”的揭示动画。

但第二幕的引擎没有删。
图片/视频图层、时间轴、扫描线、CRT、故障、HUD、泛光和 playSecondTemplate()
都还在。内置的 xtds-character-reveal 只是一个数据驱动的空槽位，里面是 XTDS 自制的通用占位线稿，不含任何现成角色。

以后想换成自己的新形象，不需要手改 JSON：

【设置 → 启动动画 → 第二幕 → 🖼️ 导入自定义形象】

支持 PNG / JPEG / WEBP / GIF，单张最大 20MB。
宿主会校验图片文件头，改扩展名的非图片字节会被拒绝；SVG 不接受。
图片只保存在本机 ~/.dsh/startup-templates/xtds-character-reveal/，不上传。
想回到占位线稿，点「恢复内置占位」。
图片缺失或损坏时，引擎会自动回退 character-slot.svg，启动动画仍会正常结束，不会黑屏。

这个版本是 XTDS 基于 LeeRolling 的 dsh-boot-suite 做的定制 fork，不是上游官方版本。
暖白片头的原始视觉与叙事作者是沈宏宏（@6shenhonghong9）；
上游合并、修复与维护是 LeeRolling。
MIT 许可保留，原作者署名保留。

安装使用本地「安装.cmd」，不发布 npm，也没有默认在线下载地址。
在线更新和模板商店默认关闭；只有维护者显式配置 XTDS_UPDATE_REPO / DSH_STORE_URL 时才启用。

## 动态 / 评论区短版

DSH 默认只播暖白「技术档案」序章，不再自动切黑暗角色揭示。
第二幕引擎保留，设置页点「🖼️ 导入自定义形象」就能换图；
支持 PNG/JPEG/WEBP/GIF，≤20MB，拒绝 SVG，缺图自动回退占位。
