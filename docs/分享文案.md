## 短版

给 DSH 做了一个暖白「技术档案」开机序章：默认只播前半段，不再自动进入黑暗角色揭示。
第二幕的揭示引擎没有删，之后可以在设置里点按钮导入自己的形象。
基于 LeeRolling 的 dsh-boot-suite 定制；暖白视觉原作者沈宏宏。
MIT，本地安装，不发布 npm。

## 长版

**DSH 暖白开机动画 · XTDS 定制版**

默认启动只有暖白「技术档案」序章：
暖白档案底板 → 五步访问授权 → 验证通过 → 直接进入聊天。

不再自动播放后半段“黑暗中闪烁出角色”的揭示动画。

但第二幕没有被删掉。扫描线、CRT、故障、HUD、泛光、时间轴和
`playSecondTemplate()` 都保留着；内置一个不含现成角色的通用占位槽位。
后续要换成自己的新形象，不需要手改 JSON：

**设置 → 启动动画 → 第二幕 → 🖼️ 导入自定义形象**

支持 PNG / JPEG / WEBP / GIF，最大 20MB；宿主会校验图片魔数，拒绝 SVG。
图片只保存在本机，不上传；缺图或图片损坏会回退占位线稿，启动不会黑屏。

这个版本是 XTDS 基于 [LeeRolling/dsh-boot-suite](https://github.com/LeeRolling/dsh-boot-suite)
的定制 fork，不是上游官方版本。暖白片头的原始视觉与叙事作者是
**沈宏宏（@6shenhonghong9）**，上游合并维护是 **LeeRolling**。

安装方式是本地 **安装.cmd**，不发布 npm，也没有默认在线下载地址。
在线更新和模板商店默认关闭；只有维护者显式配置环境变量时才可用。

如果你喜欢这个暖白序章，请先给原作者和上游项目点 star。

**上游来源**：https://github.com/LeeRolling/dsh-boot-suite

**许可**：MIT。原始视觉署名与 XTDS 修改说明见仓库 `CREDITS.md`。
